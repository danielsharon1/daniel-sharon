# PlantFinder — Claude Code project starter

Israel-first plant discovery, price comparison, and photo search. Target deliverables: responsive Hebrew RTL web app and Chrome Manifest V3 extension using a shared backend.

**Status:** specification and Claude Code instructions only. Application and extension are not implemented yet.

## Start in Claude Code Desktop / CLI
1. Extract the archive to a local folder.
2. Open that folder in Claude Code. Claude Code reads `CLAUDE.md` as project instructions.
3. Paste `CLAUDE_START_PROMPT.md` as the first task.
4. Review requested permissions and any decisions requiring approval.
5. Follow progress in `docs/RELEASE_STATUS.md` once generated.

## Included
- `CLAUDE.md`: persistent engineering instructions.
- `CLAUDE_START_PROMPT.md`: implementation kickoff prompt.
- `.claude/skills/plant-search/SKILL.md`: project skill definition.
- `docs/`: requirements, architecture, source audit, roadmap and decisions.

The sample scenario is Monstera, Netanya, 25 km, max ₪150, all authorized sources. Never misrepresent demo data as live results.
